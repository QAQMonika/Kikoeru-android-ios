# 百度网盘手机直连说明

> 普通用户请优先阅读仓库根目录 [`README.md`](../../README.md) 中的「百度网盘直连配置与使用教程」（含开放平台 AppKey 申请与 `/apps/<应用名>` 路径说明）。

不需要电脑常开、NAS、自建服务器、OpenList 或手机上的服务端辅助程序。
开发和自动测试使用合成凭据，没有读取或预置用户的真实 AppKey / SecretKey。

## 首次连接

1. 保留旧版和应用数据，使用同证书新版覆盖安装，不要先卸载。
2. 从作品页顶部切换到「网盘」（或底栏「更多 → 云端作品」），按页面提示点「应用配置」（也可切到网盘后点底栏「更多 → 应用配置」）。
3. 在手机里填写自己的 **AppKey** 和 **SecretKey**，不是 AppID；SignKey 和 ShareSecret 不需要填写。
4. 保存后会出现设备授权码。点「打开百度授权」，在百度官方页面完成登录、输入设备码并确认授权，然后回到软件等待结果。
5. 点击「选择作品目录」后，选择「浏览文件夹」，进入装有作品的文件夹并点击「使用此目录」；也可选择「直接输入路径」（个人应用受限于 `/apps/<应用名>` 时特别有用），不先读取上级目录，填写网盘完整路径。旧版已设置为具体目录时会沿用，未设置或旧根目录为 `/` 时需要选择一次。
6. 点选音轨才启动播放，浏览文件夹、打开播放器或播放列表不会自动出声。

选目录时需要临时读取上级文件夹列表供选择；选定后，普通列表、目录跳转、收藏显示和新封面读取只在该文件夹及其子目录进行。旧收藏不会删除，在选回原目录后可见。云端右上角「更多」→「选择作品目录」可更换；选择器一次最多显示 1000 项，找不到时可输入路径。这里限制的是应用内浏览范围，不会更改百度授权本身的范围。

本版使用设备码流程，不读取百度客户端 Cookie，也不需要先配置 OAuth 回调页面。
百度授权页最终显示的授权范围由百度决定；`netdisk` 范围不等于平台只读权限。
本软件可以读取，也可在用户逐次确认后上传副本；没有调用网盘删除、移动或重命名接口。
若应用权限、接口配额或百度策略不允许访问，会提示错误，不能把「应用上线」等同于所有 API 已获准。

## 文件组织

```text
作品目录/
  作品一/
    cover.jpg
    01.wav
    01.lrc
    02.flac
    02.vtt
  作品二/
    img/
      cover.jpg
    01.mp3
    01.lrc
```

- 音频与字幕保持同目录、同文件名主体；同名 LRC 优先于 VTT。
- 支持原本地库识别的音频扩展名。不要只上传 ZIP/RAR 压缩包，本版不在线解压。
- 独立封面优先选择 cover/folder/front/jacket/main/封面/表紙 等图片，向下最多扫描 4 层子目录，并对返回字节数进行一致性校验以拦截网盘占位图；无独立图片或被拦截时，尝试音频内嵌封面及 RJ 官方原版高清封面回退。
- 音频内嵌封面按需尝试 WAV RIFF ID3、FLAC Picture、MP3 ID3 和 M4A 内嵌封面；M4A 使用 Android 媒体元数据读取器，通过 Range 跳过音频主体（上限 16 MiB；独立图片上限 48 MiB），不支持 Range 或超过大小上限则继续回退或保留占位图。单张预览优先队列调度，最多搜索前 200 项及最多 4 首音轨。
- 云端首页双列预览文件夹，有音轨的目录使用文件列表。每页 200 项，可继续加载；搜索只过滤当前已加载项目。
- 音轨队列会读取当前目录所有条目，以自然顺序排列。目录达到约一万项时要求分目录，不静默截断播放队列。

## 播放与管理

- 沿用原播放器、字幕整句点击跳转、2.5 秒空闲回位和现有字幕效果。
- 「记住播放位置」开关同样控制云端音轨。位置按百度账号和文件 ID 记录，不使用会过期的下载链接作为身份。
- 退出播放器只返回真实打开它的页面；云端子目录返回作品目录；播放列表仍从菜单主动打开。
- 播放页按 64 位作品标识匹配封面；先查当前音轨文件夹，再查明确的 RJ 作品边界，或音频目录的直接父目录，不回退到普通合集根目录。若根目录本身是 RJ 编号作品，可作为该作品的上级封面。当前音轨的内嵌封面也会在后台有界尝试；非标准目录名称可能无法自动识别作品边界。
- 播放页图片保留 fitCenter，最大高度 292dp；字幕列表从 300dp 开始，避免封面下部被字幕覆盖。
- 长按云端文件夹加入或取消本机云端收藏，与在线「想听」及本地收藏互不影响。
- 首版没有把云端记录合并到现有历史列表；已有在线/本地历史不变。
- 云端更多可跳转到当前作品目录内的路径。选择器无权读取上级目录时，可直接输入自己的已授权应用目录；不能借此绕过平台权限。
- 「断开本机连接」清除本机访问/刷新令牌，保留应用配置和播放位置，不等同于在百度侧撤销应用授权。
- 需要彻底撤销时，在百度的授权管理中操作。不要把密钥、令牌或包含它们的截图发到聊天或公开仓库。

## 应用内上传（试用版）

1. 先在「云端作品」中连接百度账号并选好作品目录；该账号必须有目标目录的写入权限。百度可能限制个人应用只能写入特定应用目录，具体以实际返回为准。
2. 在「本地作品」里长按要上传的作品文件夹，选择「上传到百度网盘」。程序只读取系统授权的本地目录，先扫描，未确认前不上传。
3. 确认目标目录、文件数量和文件夹名称。**会上传所选目录的所有文件及子目录**，不仅是音频和字幕；可修改云端文件夹名。点击「确认上传」才开始。
4. 上传页显示校验、上传进度和取消入口；本地管理里的「查看上传任务」可重新打开当前进度。上传时建议保持该页面打开，亮屏时会阻止自动息屏。
5. 当前按 4 MiB 分片，逐块核对 MD5，并在创建后核对云端路径和文件大小；这不是下载整部文件做端到端校验。同名目录或文件使用 `rtype=0` 停止，不覆盖或删除已有内容。

上传只复制、不移动或删除本地原文件；上传运行期间禁止本地删除任务。取消、失败或系统中断时，已经创建的云端目录和文件会保留，不做自动清理。本版任务只保存在应用进程内，进程被系统结束后不能自动续传；重试时可另取文件夹名。较大的文件会先读取计算校验值，再读取上传，耗时和速度取决于手机、网络与百度实际限制。建议先用小测试目录验证，确认网盘内容无误后再处理原文件。

## 安全与缓存

AppKey、SecretKey 和令牌使用 AndroidKeyStore AES-GCM 加密，原子保存在应用私有的 no-backup 目录。
没有明文回退，没有硬编码真实密钥。配置框禁用状态保存、自动填充和截图，并请求输入法关闭个性化学习。
授权与接口请求只访问百度官方 HTTPS 地址，下载跳转限定百度所属域名；不使用公共解析站或第三方授权中转。
临时下载链接只短时保存在内存；播放队列和位置记录保存稳定的 `kiko-baidu://账号/文件ID`。
云端数据源与 asmr.one 的登录令牌、请求头相互独立，原在线和本地数据源继续使用原实现。

音频按需缓冲，不预先整部下载，也不创建持久音频缓存。封面缓存控制在约 96 MiB，超过后清理到约 80 MiB。
单张独立封面最大读取 48 MiB，音频内嵌封面最大读取 16 MiB，单字幕最多 4 MiB。云端更多里的「清理封面缓存」仅清理本应用缓存，不动网盘文件。
封面后台加载，不等待图片下载再启动音频。

## 验证边界

2026-11-04：1587 项 JVM 检查通过，包括 64 位播放标识、同作品封面回退和跨账号/目录隔离；包内播放器 fitCenter 和间距检查通过。上传仍以合成文件夹和 HTTPS 验证，M4A 适配器使用假系统读取器，并未运行 Android 原生 M4A 解码器。
打包桥接、图标资源、DEX 上限、对齐及原证书 v3 签名检查通过；没有真实密钥或测试类进入 APK。
本轮没有覆盖安装或操作用户手机，没有访问真实账号，也没有上传、删除、播放用户文件。
用户提供的旧版截图显示真实账号已有目录列表及部分封面；本版播放页、M4A 封面、真实网盘写入权限、实际上传和 SVIP 速度尚无真实手机验证，不能把构建成功当成这些体验已通过。

建议先上传一部带独立封面和同名字幕的作品，测试授权、起播、跳转、暂停续播和重启恢复，再批量迁移。
网络、会员通道、音频本身的索引以及百度 Range 支持均会影响体验。
服务器忽略 Range 时会明确拒绝非零位置跳转，不为跳转悄悄下载整首；过期链接在后续打开时会重取并限次重试。
